# Komorebi Coffee

架空のカフェ「Komorebi Coffee」の Web サイトです。ポートフォリオ用に制作しました。

## 概要

自家焙煎のスペシャルティコーヒーと手づくりの焼き菓子を出す、小さな街のカフェを想定したサイトです。

| ページ | 内容 |
|---|---|
| `index.html`（トップ） | コンセプト・メニュー・ギャラリー・お知らせ・アクセス・お問い合わせ |
| `coffee.html`（コーヒー） | 焙煎度ガイドと、コーヒー豆 8 種類の産地・味の特徴（酸味・苦味・コク） |
| `sweets.html`（お菓子） | ケーキ・焼き菓子・季節限定の 8 品と、合わせたいコーヒー |

## 使用技術

- HTML5
- CSS3（CSS Grid / Flexbox / カスタムプロパティ / アニメーション）
- JavaScript（フレームワークなし）
- Vite（ローカル開発サーバーとしてのみ使用）

## 主な機能・工夫した点

- **レスポンシブ対応**：PC・タブレット・スマホで見やすいレイアウト
- **スマホ用ハンバーガーメニュー**
- **複数ページ構成とページ遷移アニメーション**（CSS の View Transitions。未対応ブラウザではフェードイン）
- **メニューのタブ切り替え**（キーボードの左右キーでも操作可能）
- **カードの絞り込み**：焙煎度・お菓子の種類で絞り込み（`data-category` 属性を使った共通の仕組み）
- **味の 5 段階メーター**：CSS 変数（`style="--v:3"`）だけで表示
- **スクロールに合わせたフェードイン**（Intersection Observer）
- **お問い合わせフォームの入力チェック**（デモのため実際には送信されません）
- **自作の SVG イラスト**（ギャラリー・お菓子・地図）と CSS で描いたコーヒーカップ
- **アクセシビリティへの配慮**：aria 属性、`prefers-reduced-motion` 対応

## フォルダ構成

```
.
├── index.html          … トップページ
├── coffee.html         … コーヒー豆の種類
├── sweets.html         … お菓子
├── css/
│   └── style.css       … 全ページ共通のスタイル
├── js/
│   └── main.js         … 全ページ共通のスクリプト
└── images/
    ├── favicon.svg
    ├── gallery-*.svg   … ギャラリーのイラスト
    ├── sweet-*.svg     … お菓子のイラスト
    └── map.svg         … アクセスの地図
```

> イラストは `images/` に写真（.jpg など）を置き、HTML の `src` を書き換えると差し替えられます。

## ローカルでの確認方法

### pnpm（Vite 開発サーバー）

```bash
pnpm install   # 初回のみ
pnpm run dev   # http://localhost:5173 がブラウザで開きます
```

### VS Code の Live Server

1. 拡張機能「Live Server」をインストール（フォルダを開くと推奨が表示されます）
2. `index.html` を右クリック →「Open with Live Server」
